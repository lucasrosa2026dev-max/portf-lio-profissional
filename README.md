```text
├── index.html

```

## Como visualizar

Abra `index.html` no navegador. A foto está em `assets/images/lucas-santos.jpg`. Para fontes personalizadas, é necessária conexão com a internet.

## Publicação no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie **o conteúdo desta pasta** para a raiz do repositório (não a pasta inteira).
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`; clique em **Save**.
4. Aguarde a publicação e abra o link informado em **Settings → Pages**.

## Personalização

Edite os textos, links de projetos e contatos no `index.html`.
